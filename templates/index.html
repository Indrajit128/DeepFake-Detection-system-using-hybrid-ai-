🏗️ Architectures

🧠 CBAM Deep Learning

CNN + Convolutional Block Attention Module. Channel & spatial attention after every conv block. Best at detecting subtle GAN artefacts.

🖥️ CNN Deep Learning

4-block baseline CNN. Conv-BN-ReLU-MaxPool + Global Average Pooling + dense head. Input: 128×128×3.

📐 SVM Classical ML

RBF kernel SVM with Platt probability calibration. Features: HOG histogram + PCA(128).

〰️ Ridge Classical ML

L2-regularized linear classifier. Fast and stable. Same HOG + PCA(128) feature pipeline.

🔻 Lasso Classical ML

L1 logistic regression. Sparse feature selection. Trained on HOG + PCA(128) features.
