🏗️ Model Architectures

🧠 CBAM Deep Learning

CNN + Convolutional Block Attention Module. Channel & spatial attention gates after every conv block. Best for subtle forgery artefacts.

🖥️ CNN Deep Learning

4-block baseline CNN. Conv-BN-ReLU-MaxPool layers followed by Global Average Pooling and a dense classifier. Input: 128×128×3.

📐 SVM Classical ML

Support Vector Machine with RBF kernel and Platt scaling for probability estimates. Features: HOG + PCA(128).

〰️ Ridge Classical ML

L2-regularized linear classifier. Fast and stable, trained on HOG histogram features compressed via PCA to 128 dimensions.

🔻 Lasso Classical ML

L1 logistic regression promoting sparse feature selection. Same HOG + PCA(128) pipeline as Ridge and SVM.
